# P4-P5 checkpoint

阶段：P4 架构与主动门控、P5 checkpoint 与崩溃恢复  
目标：补齐能力矩阵、安全主动适配器和持久化恢复边界。  

已完成：

- `CapabilityRegistry`：能力、主动等级、成本、分页/恢复/取消、外部副作用、重试和敏感数据策略。
- `SafeHttpAdapter`：仅允许授权上下文中的 HTTP/HTTPS GET 观察，拒绝状态变更和未配置传输。
- `SafePortAdapter`：仅允许授权端口验证，拒绝未授权端口和端口范围扫描。
- 架构状态门控：第三方、源站候选、未知状态必须人工复核。
- SQLite migration 2：动作 attempt、started/completed 时间和 error_code，新增 adapter_registry。
- checkpoint 原子写入与最新有效 checkpoint 读取。
- `started` 无终态恢复为 `unknown`，记录外部终态不确定事件，禁止盲目重放。
- `checkpoint`、`recover`、`pause`、`resume`、`cancel` CLI。
- Coordinator 在动作执行和归并阶段创建 checkpoint。

测试命令：

```powershell
uv run pytest -q
```

测试结果：`16 passed`。  
已知限制：子 Agent lease/heartbeat、Playwright 观察和完整预算/时间窗执行器仍属于 P6/后续增量。  
恢复位置：最新有效 checkpoint、动作表和事件表；无终态外部动作恢复为 `unknown`，需人工判断后再重试。
