## 已完成

  - 新 `service` 资产类型：normalized_value `<ip>:<port>/<protocol>`，scope
    归属按内嵌 IP 判定（授权 IP 上的服务 confirmed，但证据置信度仍受上限）。
  - 提取器 `_extract_fofa`（source=`fofa_mcp`）：host↔ip 强关系
    `fofa_host_ip`（计划 §12.2 明示强关联）、domain 字段 `fofa_domain_ip`、
    `service_ip` 强关系；**title/product 不产资产**——单标题/横幅不能确认
    产品（§12.3），留作 R6 指纹证据。跨源佐证生效（DNS+FOFA 同 IP 置信度
    0.7→0.8）。
- **R4.5 报告接入**（`reporting/export.py`）：JSON 新增 `asset_relations`/
  `asset_conflicts`/`merge_summary`（confirmed/candidate/third_party 计数、
  关系数、未解决冲突数、来源清单）；XLSX 新增 `资产关系`/`归并冲突` 工作
  表（冲突表头显式、公式注入防护沿用 `_excel_safe`）。
- **R4.6 衰减与生命周期**（migration 11：`asset.current_status`、
  `asset_relation.current_status`/`last_transition`）：
  - 时间衰减：`freshness_decay` 确定性分级（≤7 天 0、8-30 天 -0.1、>30 天
    -0.2），confidence 下限 0.2；scope 锚点永不衰减（用户授权不是会老化的
    证据）。同日重跑字节一致，跨时间衰减是设计行为。
  - 关系生命周期：依附锚点+类型最近一次观察的值集合——new（新增）、
    current、disappeared（脱离最新集合）、reappeared（重现/临时变化后回
    归）；identical 重复观察不构成佐证；资产级 rollup：非 scope 资产全部
    入边 disappeared 时资产标记 disappeared，scope confirmed 资产与锚点
    永不消失；生命周期移动不改变 relation 的 confirmed/candidate 授权语义。

## 已知限制

- FOFA 观察质量依赖 R2 查询字段（fields）配置：若查询未取 ip/port 字段，
  对应资产不会生成（数据驱动的诚实行为）。
- 生命周期以"锚点+类型最近一次观察"为当前集合：乱序导入的历史观察会被
  当作较旧数据（rowid 序即导入序）。
- 衰减参数（7/30 天、幅度）为初始冻结值，调整属策略变更需记录。
- 报告 XLSX 的 JSON 列（sources_json/architecture_json/provenance_json）以
  文本呈现，人读可接受；结构化展开属 R7 统一报告。
